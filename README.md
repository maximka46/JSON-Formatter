# 🧾 JSON Formatter

A simple JSON formatting project implemented in multiple programming languages.

---

## 📖 Overview

This repository demonstrates how to format and pretty-print JSON data using:

- JavaScript
- Python
- C#
- PHP

Useful for:

- API development
- Debugging
- Configuration files
- Structured data analysis

---

## ✨ Features

- Pretty JSON formatting
- Cross-language examples
- Beginner-friendly code
- Readable output

---

## 📂 Structure

```text
javascript/
python/
csharp/
php/
```

---

## Example

### Input

```json
{"name":"Max","age":25,"city":"Kyiv"}
```

### Output

```json
{
    "name": "Max",
    "age": 25,
    "city": "Kyiv"
}
```

---

## Running

### JavaScript

```bash
node formatter.js
```

### Python

```bash
python formatter.py
```

### C#

```bash
dotnet run
```

### PHP

```bash
php formatter.php
```
